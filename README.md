# Booking & Scheduling System - Schedule-Master
[Click here to visit the live web app!](https://schedule-master-makc.onrender.com/)



#### Description:
This web application is a scheduling and appointment booking system built for CS50, featuring separate interfaces for clients and service owners. It allows clients to register, log in, search for availability, and manage their bookings, while providing owners with dedicated tools to set their schedules and manage incoming appointments. 

## Features
* **Role-Based Interfaces:** Distinct navigation and layout views for clients and owners to ensure tailored functionality.
* **Appointment Booking:** Clients can search for available slots, book appointments, and view their personal booking history.
* **Schedule Management:** Owners can set their availability, view schedules, and manage client bookings.
* **User Authentication:** Secure user registration, login, and session handling.

## Technologies Used
* **Backend:** Python, Flask
* **Database:** SQLite3
* **Frontend:** HTML, CSS, Jinja2 Templates

## Project Structure
* `app.py`: The main application controller containing the backend routing and logic.
* `clients.db`: The SQLite database storing users, appointments, and schedule data.
* `tempCodeRunnerFile.py`: Temporary execution file generated by the code editor.
* `templates/`: Directory containing all user interface files.
    * `base.html`, `layout_client.html`, `layout_owner.html`: Core layout files providing the foundation and role-specific navigation menus.
    * `login.html`, `register.html`: Templates handling user account creation and authentication.
    * `indexf.html`, `indexo.html`: The main dashboard views tailored for clients and owners.
    * `book.html`, `make.html`, `mybooking.html`: Client-facing pages used to create, finalize, and review personal appointments.
    * `Sechdule.html`, `set.html`, `show.html`, `veiw_s.html`: Owner-facing scheduling pages to establish availability and review upcoming agendas.
    * `search.html`: Search interface for finding specific availability or records.
    * `error.html`: Custom display for application errors.
